# OrganScore Studio

OrganScore Studio is a Windows desktop application for importing PDF, PNG, and JPEG sheet music; recognizing printed notation with Audiveris; reviewing MusicXML; and playing multi-page organ scores.

## Release 1.1.5 highlights

- Clickable translucent playback measure highlighting
- Playback highlighting across measures and pages
- Click a measure to select it or seek playback there
- Loop playback returns to the beginning
- PDF-to-MusicXML export
- Multi-page score and SATB playback support
- 74 tests and 10 subtests passed
